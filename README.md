# ShortcutForge

**Build Apple Shortcuts from typed JSON with an AI harness or by hand.** ShortcutForge is a Python 3.11+ command-line toolkit and reusable Codex/Claude Code Skill. It validates a small, explicit action schema and compiles plans to binary property lists. The model interprets intent; the Python package handles deterministic work.

[日本語](README.ja.md) · [Documentation index](docs/README.md) · [Contributing](docs/contributing.md) · [MIT License](LICENSE)

> **Compatibility:** Binary plist output does not establish that Apple Shortcuts will import or run a workflow. Signing through GitHub-hosted macOS is currently blocked because the runner is not signed in to iCloud. Review [known limitations](#known-limitations) before relying on generated files.

## What it does

- Builds `.shortcut` files from a versioned JSON plan on Windows, macOS, or Linux.
- Validates known actions, parameters, plist-compatible values, and output references before writing.
- Inspects existing workflow plists without executing their actions.
- Provides a searchable action discovery catalog scoped to iOS 17, 18, 26, or 27, with English and Japanese Markdown guides.
- Provides a harness-neutral Skill so an AI agent can translate a request into a plan and invoke the CLI.

ShortcutForge has no GUI, server, LLM API, or runtime dependency outside the Python standard library.

## Quick start

Requires Python 3.11 or newer.

```sh
python -m pip install .
shortcutforge build examples/hello.json -o Hello.shortcut
shortcutforge validate Hello.shortcut
shortcutforge inspect Hello.shortcut
```

Use `python -m shortcutforge` instead of `shortcutforge` if the script entry point is not on `PATH`.

## Create a shortcut by hand

Plans are ordinary JSON, so they can be edited in any text editor or generated by an AI harness.

```json
{
  "version": 1,
  "name": "Notify current time",
  "actions": [
    {"id": "current_date", "as": "now"},
    {"id": "notify", "params": {"text": {"ref": "now"}}}
  ]
}
```

Build, validate, and inspect it:

```sh
shortcutforge build plan.json -o NotifyCurrentTime.shortcut
shortcutforge validate NotifyCurrentTime.shortcut
shortcutforge inspect NotifyCurrentTime.shortcut
```

The [JSON plan reference](docs/json-plan-format.md) describes readable action IDs, Apple parameter keys, raw action identifiers, and output references. For raw actions, obtain identifiers and parameters from a compatible shortcut or a trusted source; structural validation cannot establish runtime compatibility.

## Action catalog by iOS version

Always select the intended target version. The catalog distinguishes observed evidence from unknown availability; a version selector is not a compatibility guarantee.

```sh
shortcutforge actions list --os 27 --query notification
shortcutforge actions list --os 26 --lang ja --format markdown --output ios26-actions.ja.md
shortcutforge actions list --os 18 --format json
```

Read the [English catalog guide](docs/action-catalog.en.md), [Japanese catalog guide](docs/action-catalog.ja.md), and [catalog sources and coverage](docs/action-catalog-sources.md). Corrective and additive pull requests are welcome; see [contribution guidance](docs/contributing.md).

The same catalog can be used from Python:

```python
from shortcutforge import ActionCatalog, IOSVersion

catalog = ActionCatalog.from_package()
actions = catalog.list_actions(IOSVersion.IOS_26, query="calendar")
availability = catalog.get_availability(
    "is.workflow.actions.notification", IOSVersion.IOS_26
)
markdown = catalog.render_markdown(
    IOSVersion.IOS_26, language="ja", query="calendar"
)
```

## AI harness Skill

`skills/shortcutforge/SKILL.md` works with Codex and Claude Code. Install the package, then copy or link the `skills/shortcutforge` directory into the relevant harness skill directory. The Skill asks the model to interpret the request and produce JSON; ShortcutForge itself makes no model/API calls. See the Skill file for exact installation paths and its safety workflow.

## Commands

| Command | Purpose |
| --- | --- |
| `shortcutforge build PLAN -o FILE` | Validate a JSON plan and compile a binary plist. |
| `shortcutforge validate FILE` | Check plist structure; does not validate Apple action semantics. |
| `shortcutforge inspect FILE` | Print the workflow name and action identifiers without running it. |
| `shortcutforge actions list --os VERSION` | Search the version-scoped action discovery catalog. |
| `shortcutforge sign FILE` | Dispatch the configured GitHub Actions signing workflow. See [signing status](docs/signing-validation.md). |

Run `shortcutforge COMMAND --help` for options.

## Known limitations

- The build-time convenience schema supports only `current_date`, `text`, `notify`, `speak`, and `open_url`. Raw Apple actions receive basic structural checks only.
- Variables/output references are supported for the existing linear action format. Conditional and repeat compilation, and a calendar action implementation, are not available.
- The 2,501-identifier discovery catalog is not a complete Apple schema. iOS 27 identifiers have simulator evidence; iOS 17, 18, and 26 compatibility is unknown or based on partial change reports.
- No real iPhone import or runtime test has been completed. iOS 27 import is unverified.
- GitHub-hosted macOS signing was tested and failed with Apple's “you must be signed into iCloud” requirement. No signed artifact is produced by that path today. See [signing validation](docs/signing-validation.md).
